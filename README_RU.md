# История крутого чувака — версия 1.0 (прототип)

## Что добавлено в 1.0
- Процедурный район Южный: дороги, дворы, дома, парк, остановка и холмистый рельеф по краям карты.
- Персонаж и NPC из простых стоковых по стилю 3D-заготовок — без реальных лиц и голосов.
- Первая сюжетная цепочка: поговорить с соседом, дойти до остановки и вернуться во двор.
- Субтитры диалогов и отображение текущего задания.
- Телефон с лентой коротких мемов и переключением между ними.
- Сенсорное управление для Android и управление клавиатурой/мышью на ПК.

## Важно о карте
Это игровая стилизованная реконструкция Южного, а не точная геодезическая копия. Рельеф и расположение объектов пока условные; реальные улицы и высоты нужно будет сверить отдельно и затем уточнить.

## Управление
**ПК**
- WASD — движение.
- Shift — бег.
- Space — прыжок.
- Мышь — камера.
- E — взаимодействие с персонажами.
- F — открыть/закрыть телефон.
- Esc — отпустить курсор.

**Android**
- Левый виртуальный джойстик — ходьба.
- Правая часть экрана — поворот камеры.
- «БЕГ» и «ПРЫЖОК» — движение.
- «ВЗАИМОДЕЙСТВОВАТЬ» — разговор/действие.
- «ТЕЛЕФОН» — открыть ленту мемов.

## Запуск
Открой папку проекта в Godot 4.3 и запусти scenes/main.tscn.

## APK
Debug APK собирается автоматически через GitHub Actions при каждом push в main. Готовый APK находится в Artifacts последней успешной сборки (артефакт хранится 14 дней).

## Основные файлы
- project.godot — настройки проекта.
- scenes/main.tscn — стартовая сцена.
- scripts/player.gd — персонаж, камера и сюжетная логика.
- scripts/mobile_controls.gd — сенсорное управление.
- scripts/game_hud.gd — телефон, мемы, задания и субтитры.
- scripts/world.gd — рельеф, район, дома и NPC.
