# История крутого чувака — Android-ready prototype 0.2

## Важно
Это исходный проект Godot, подготовленный для Android и Windows. Это **не готовый APK**: для APK нужна сборка через Godot Editor с установленными Android export templates, Android SDK и JDK. В этой среде сборка APK не выполнялась.

## Открытие
1. Скачай и распакуй архив.
2. Открой папку через Godot 4.3 или новее.
3. Нажми Run для тестирования на компьютере.

## Сенсорное управление
- Левый виртуальный джойстик — ходьба.
- Правая часть экрана — поворот камеры.
- Кнопка «БЕГ» — ускорение, пока палец удерживает кнопку.
- Кнопка «ПРЫЖОК» — прыжок.

На ПК также работают WASD, Shift, Space и мышь.

## Экспорт APK (потребуется компьютер)
В Godot: Editor → Manage Export Templates → Download and Install.
Затем Editor → Export → Add… → Android. Установи Android SDK/JDK по инструкции Godot, настрой пути в Editor Settings → Export → Android и нажми Export Project.
Для тестирования можно выбрать debug APK.

## Состав
- `project.godot` — настройки проекта.
- `scenes/main.tscn` — стартовая сцена.
- `scripts/player.gd` — персонаж и камера.
- `scripts/mobile_controls.gd` — сенсорный джойстик и кнопки.
- `scripts/world.gd` — тестовый блок-аут района.

Карта пока условная, не точная географическая копия посёлка Южного. Следующий этап — сверить реальную планировку, затем заменить примитивы на детализированные модели и материалы.
