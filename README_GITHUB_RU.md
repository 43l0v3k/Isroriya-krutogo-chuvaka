# История крутого чувака — сборка Android APK через GitHub

Репозиторий содержит исходный Godot-проект и GitHub Actions workflow для сборки тестового debug APK.

## Как получить APK
1. Открой вкладку Actions.
2. Выбери Build Android APK.
3. Нажми Run workflow.
4. После успешного завершения открой запуск и скачай artifact istoriya-krutogo-chuvaka-debug-apk.
5. Распакуй ZIP и установи APK на Android.

Сборка также запускается автоматически при push в main.

## Важно
- Это тестовый прототип, а не готовая полноценная GTA-подобная игра.
- APK будет debug-сборкой.
- Успешность сборки ещё не проверена; результат станет известен после запуска workflow.
- Не публикуй личные фотографии, голоса, адреса или другие данные друзей без их согласия.
